Aero specialist pipeline - October 10, 2026

This package is personal constructed FEA verification evidence, not design certification.
For each solver/<case>/ directory, run CalculiX with: ccx -i model
The retained solver version is CalculiX 2.23. Units are N, mm, MPa and K.
meshes/ retains each actually executed refinement deck and output.
cases.json preserves original request, raw reader response, expected fields, decisions and unit trace.
report.json separates fresh inference, retrospective replay and stock reviewer diagnostics.
Model weights and private host execution logs are not included; the ZIP reproduces numerical cases, not the complete private model deployment.
Inspect proof.pdf and render_provenance.json for observable definitions, field averaging and limitations.
manifest.json establishes per-file identity, not independent scientific correctness.
